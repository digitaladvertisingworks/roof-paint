# Sydney Roof Paint and Coatings Static Website

Cloudflare Pages-ready static website package for roof paint and coatings services in Sydney, NSW.

## Structure
- `index.html` — SEO-optimized homepage targeting roof paint and coatings Sydney.
- `services.html` — service hub for roof painting, protective coatings and restoration preparation.
- `locations/index.html` — location index.
- `locations/*.html` — 36 unique suburb/postcode pages.
- `assets/css/styles.css` — mobile-first shared CSS variables and reusable components.
- `assets/js/main.js` — minimal accessible mobile navigation.
- `robots.txt`, `sitemap.xml`, `_headers` — Cloudflare/static deployment helpers.

## Notes
- No structured data markup included, per request.
- Uses semantic HTML5: header, nav, main, section, article, aside and footer.
- Content is BERT-friendly, NLP-rich and organised around service, material, problem and local vectors.
- Replace `https://example.com` in `sitemap.xml` and `robots.txt` with the live domain before publishing.
